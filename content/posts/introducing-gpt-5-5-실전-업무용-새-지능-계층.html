Introducing GPT-5.5 — 실전 업무용 새 지능 계층

Source: https://openai.com/index/introducing-gpt-5-5
Published: 2026-04-23

Summary

OpenAI가 GPT-5.5를 공개했다. 발표의 핵심 메시지는 “더 똑똑해진 모델” 자체보다도, 복잡한 실제 업무를 컴퓨터 위에서 끝까지 수행하는 능력이 한 단계 올라갔다는 점이다. GPT-5.5는 코딩, 웹 리서치, 데이터 분석, 문서/스프레드시트 작성, 소프트웨어 조작 같은 작업에서 여러 도구를 넘나들며 계획·실행·검증을 이어가는 사용성을 전면에 내세운다.

OpenAI는 GPT-5.5가 GPT-5.4 대비 더 높은 성능을 보이면서도 실제 서빙 지연은 GPT-5.4와 같은 수준으로 맞췄고, Codex 작업에서는 더 적은 토큰으로 더 좋은 결과를 내는 경우가 많다고 설명한다. 동시에 사이버 보안·생물/화학 영역에 대한 강화된 안전장치와 신뢰 기반 접근 정책을 함께 발표했다.

발표 요지

OpenAI는 GPT-5.5를 “가장 똑똑하고, 가장 직관적으로 사용할 수 있는 모델”로 소개한다. 이 모델은 사용자의 의도를 더 빨리 파악하고, 작업의 더 큰 비중을 스스로 떠안는 방향으로 설계되었다. 핵심 사용 시나리오는 다음과 같다.

  • 코드 작성·디버깅
  • 웹 리서치와 정보 수집
  • 데이터 분석
  • 문서·스프레드시트 생성
  • 소프트웨어 조작 및 도구 간 이동
  • 애매한 요구사항을 스스로 정리하고 끝까지 진행하는 장기 작업

OpenAI는 특히 agentic coding, computer use, knowledge work, 초기 과학 연구 영역에서 성능 향상이 두드러진다고 강조한다. 요지는 “한 단계 더 똑똑해졌다”가 아니라, 불완전한 지시를 받아도 계획을 세우고 도구를 쓰고 결과를 점검하면서 일을 끝까지 밀어붙이는 능력이 강화되었다는 것이다.

모델 역량: 코딩·지식노동·컴퓨터 사용

1) Agentic coding

GPT-5.5는 OpenAI가 공개한 기준에서 가장 강한 agentic coding 모델로 소개된다. Codex 안에서는 구현, 리팩터링, 디버깅, 테스트, 검증 같은 엔지니어링 업무를 더 안정적으로 수행하며, 큰 코드베이스의 문맥 유지·애매한 장애 원인 추적·도구로 가정 검증·주변 코드까지 반영하는 능력이 좋아졌다고 설명한다.

대표 수치:

Terminal-Bench 2.0 82.7% 75.1% 69.4% 68.5%
SWE-Bench Pro (Public) 58.6% 57.7% 64.3% 54.2%

OpenAI는 초기 사용자 피드백도 함께 제시한다. 시스템 구조를 더 잘 파악하고, 실패 원인과 수정이 들어가야 할 위치를 더 잘 짚으며, 테스트·리뷰 필요사항을 미리 예측하는 경향이 강해졌다는 평가다.

2) Knowledge work

GPT-5.5는 단순 답변형 모델이 아니라, 정보 탐색 → 핵심 파악 → 도구 사용 → 산출물 검증 → 문서화까지 이어지는 지식노동 루프를 더 자연스럽게 수행하는 방향으로 설명된다. OpenAI 내부 사례로는 다음이 언급된다.

  • Comms 팀: 6개월치 speaking request 데이터를 분석해 점수화·리스크 프레임워크를 만들고 Slack 자동화 검증
  • Finance 팀: 24,771개의 K-1 세금 양식(총 71,637쪽) 검토 워크플로 가속
  • GTM 팀: 주간 비즈니스 리포트 자동화로 주당 5~10시간 절감

ChatGPT 측면에서는 GPT-5.5 Thinking이 더 빠르고 간결하게 어려운 문제를 풀도록 설계되었고, GPT-5.5 Pro는 더 높은 정확도와 난도 높은 업무를 겨냥한 상위 버전으로 소개된다.

3) Computer use / tool use

OpenAI는 GPT-5.5가 화면을 보고 클릭·입력·탐색하며 여러 도구를 정밀하게 오갈 수 있는 방향으로 발전했다고 설명한다. OSWorld-Verified, BrowseComp, Toolathlon, Tau2-bench Telecom 같은 지표를 통해 실제 컴퓨터 조작·툴 사용 성능을 강조한다.

차세대 추론 효율: 같은 지연, 더 높은 성능

OpenAI는 GPT-5.5를 GPT-5.4와 같은 수준의 지연(latency)으로 서비스하기 위해 추론 시스템 전체를 다시 설계했다고 설명한다. GPT-5.5는 NVIDIA GB200 / GB300 NVL72 시스템에 맞춰 공동 설계·학습·서빙되었고, Codex와 GPT-5.5 자체가 이 인프라 최적화 과정에도 활용되었다고 한다.

특히 강조된 사례는 로드 밸런싱과 파티셔닝 휴리스틱 개선이다. 이전에는 요청을 고정된 수의 청크로 나누어 GPU 코어에 분배했지만, 모든 트래픽 패턴에 최적은 아니었다. Codex가 수주치 production 트래픽 패턴을 분석하고 맞춤형 휴리스틱 알고리즘을 작성해 더 효율적으로 분할·분산했고, 그 결과 토큰 생성 속도가 20% 이상 향상되었다고 한다.

OpenAI의 framing은 분명하다. GPT-5.5는 단순히 더 큰 모델이 아니라, 모델·툴·서빙 인프라가 함께 최적화된 작업 수행 시스템으로 제시된다.

보안과 안전: 사이버 방어 쪽은 더 열고, 악용은 더 강하게 막기

OpenAI는 GPT-5.5의 사이버 보안 능력을 GPT-5.4보다 한 단계 올라간 것으로 평가하면서도, Critical 단계에는 이르지 않았다고 밝힌다. 대신 Preparedness Framework 상 biological/chemical 및 cybersecurity capability를 모두 High로 취급하고, 다음과 같은 조치를 강조한다.

  • 더 위험한 사이버 활동과 민감한 요청에 대해 더 엄격한 분류기 적용
  • 반복적 오남용에 대한 추가 보호
  • 인증된 사용·모니터링 기반의 접근 관리
  • 외부 전문가와 수개월간 강건성 테스트 수행
  • Trusted Access for Cyber를 통해 신뢰 신호를 충족한 검증 사용자에게는 방어 목적 사용에서 더 적은 제한 제공
  • 중요 인프라 방어 조직은 별도의 엄격한 보안 요구사항 아래 cyber-permissive 모델 접근 신청 가능

OpenAI의 메시지는 “사이버 능력이 강해질수록 전면 차단보다 검증된 방어 사용자는 더 쉽게 쓰게 하고, 악용 가능성이 높은 워크플로에는 더 강한 통제를 건다”는 방향에 가깝다. 추가 세부는 GPT-5.5 system card를 참고하라고 안내한다.

제공 범위와 가격

ChatGPT

  • GPT-5.5: Plus, Pro, Business, Enterprise 사용자에게 순차 배포
  • GPT-5.5 Pro: Pro, Business, Enterprise 사용자에게 제공
  • ChatGPT 안에서는 GPT-5.5 Thinking과 GPT-5.5 Pro 형태로 구분

Codex

  • Plus, Pro, Business, Enterprise, Edu, Go 플랜에서 사용 가능
  • 컨텍스트 윈도우: 400K
  • Fast mode: 토큰 생성 속도 1.5배, 비용은 2.5배

API (곧 제공)

  • gpt-5.5: 1M 입력 토큰당 $5, 1M 출력 토큰당 $30
  • 컨텍스트 윈도우: 1M
  • Batch / Flex: 표준 API 요금의 절반
  • Priority 처리: 표준 요금의 2.5배
  • gpt-5.5-pro: 1M 입력 토큰당 $30, 1M 출력 토큰당 $180

OpenAI는 GPT-5.5가 GPT-5.4보다 가격은 높지만, 더 높은 지능과 더 나은 토큰 효율을 제공하므로 실제 작업 단위 기준 효율은 개선될 수 있다고 주장한다.

한 줄 해석

이 글은 GPT-5.5를 “챗봇이 더 똑똑해졌다”보다 현실의 업무를 컴퓨터 위에서 더 자율적으로 수행하는 모델로 포지셔닝한다. Codex와 ChatGPT, 모델 성능과 인프라 최적화, 활용 확대와 안전 통제를 한 묶음으로 제시한 점이 발표의 핵심이다.
